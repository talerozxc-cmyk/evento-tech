# Códigos de estado HTTP

## 200 OK

La solicitud se procesó correctamente y el servidor devolvió el recurso solicitado.

## 301 Moved Permanently

El recurso fue movido permanentemente a otra URL. El navegador puede seguir la redirección hacia la nueva dirección.

## 404 Not Found

El servidor no encontró el recurso solicitado. Esto ocurre, por ejemplo, cuando intentamos acceder a una página que no existe.

## 304 Not Modified

El recurso no ha cambiado desde la última versión almacenada en caché, por lo que el navegador puede utilizar su copia almacenada.
