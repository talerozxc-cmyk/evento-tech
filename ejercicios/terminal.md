crear desde la terminal un arbol de 3 niveles con 8 archivos moverlos renombrarlos y borrar la mitad
-cree la carpeta ejercicios
-cree la carpeta terminal
-cree 3 sub carpetas html css y recursos
-cree 8 archios dentro de esas carpetas
-movi ponentes.html de html y lo pase a recursos
renombre index.html como inicio.html
-elimine 4 archivos la mitad de los que cree

html/inicio.hthml
html/agenda.html
css/estilos.css
recursos/ponentes.html

aprendizajes
mkdir para crear carpetas
new-item crear archibos
move-item para mover los archivos
rename-item para renombrar los archivos
remove-item para borrar archibos
tree para visualizar la estructura carpeta y archivos
